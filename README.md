# Mahindra & Mahindra — Interactive Equity Research

Responsive static research covering M&M business, audited FY21–FY26 results, Q2 FY27, market context, peer disclosures and valuation.

Live site: https://Revanth015.github.io/mnm-equity-analysis/  
Research cutoff: 10 November 2026  
Stack: HTML, CSS, JavaScript and Chart.js. GitHub Pages hosting is free.

Open index.html locally. Internet is needed for Chart.js and Google Fonts; text and datasets are bundled in the page. Peer scopes differ. Group borrowings include Financial Services. Tata successor entities are separated after demerger. Market returns exclude dividends. Educational, not investment advice.

The Actions workflow publishes main to GitHub Pages. If needed choose Settings → Pages → Build and deployment → GitHub Actions.
